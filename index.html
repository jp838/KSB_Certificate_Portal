Manual Installation Guides

  1. Click Copy Auto-Install Command above.
  2. Press Win + R, type powershell, and press Enter.
  3. Right-click in the window to paste, then press Enter.

Alternatively, download Fortinet_CA_SSL.cer directly to install via the Windows Wizard.

  1. Tap Download Certificate above and tap Allow.
  2. Open Settings and tap Profile Downloaded near the top.
  3. Tap Install in the top-right corner and enter your passcode.
Mandatory Step for iOS:
Go to Settings > General > About > Certificate Trust Settings.
Under "Enable full trust for root certificates", toggle ON trust for Fortinet_CA_SSL.
  1. Tap Download Certificate (.crt) above.
  2. If prompted by Android, select CA Certificate or Wi-Fi Certificate.
  3. If not prompted, open Settings → Search for CA Certificate.
  4. Select Fortinet_CA_SSL.crt from your Downloads folder.
  1. Click Download Certificate above and double-click the file to open.
  2. In Keychain Access, find Fortinet_CA_SSL under login or System.
  3. Double-click the certificate and expand Trust.
  4. Set When using this certificate to Always Trust.
  5. Close Keychain Access and enter your Mac password to confirm.
