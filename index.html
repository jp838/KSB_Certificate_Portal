Installation Guides

Option A: Automated Install (Recommended)

  1. Click Copy Auto-Install Command above.
  2. Press Win + R, type powershell, and press Enter.
  3. Right-click inside the PowerShell window to paste, then press Enter.
  4. Click Yes on the Windows prompt (UAC) to grant permission.

Option B: Manual Installation Instructions

  1. Click here to download Fortinet_CA_SSL.cer to your computer.
  2. Double-click the downloaded file and click Open.
  3. Click Install Certificate... at the bottom of the window.
  4. Select Local Machine and click Next (click Yes if prompted by Windows).
  5. Select Place all certificates in the following store and click Browse...
  6. Choose Trusted Root Certification Authorities and click OK.
  7. Click Next, then click Finish to complete the setup.
  1. Ensure you are using Safari (Chrome/Firefox/Outlook on iOS will block profile setup).
  2. Tap Install Security Profile above and tap Allow if prompted.
  3. Open the Settings app on your iPad or iPhone.
  4. Tap Profile Downloaded near the top (under your Apple ID).
  5. Tap Install in the top-right corner and enter your device passcode.
Mandatory Final Step for iOS:
Go to Settings > General > About > Certificate Trust Settings.
Under "Enable full trust for root certificates", toggle ON trust for King's School Bruton Web Security (or Fortinet_CA_SSL).
  1. Tap Download Certificate (.crt) above.
  2. If prompted by Android, select CA Certificate or Wi-Fi Certificate.
  3. If not prompted, open Settings → Search for CA Certificate.
  4. Select Fortinet_CA_SSL.crt from your Downloads folder.

Option A: Automated Terminal Command (Recommended)

  1. Click Copy Terminal Auto-Install Command above.
  2. Press Command + Space, type Terminal, and press Enter.
  3. Press Command + V to paste into Terminal and press Enter.
  4. You will be prompted for your Mac password.
  5. Select Update Settings.

Option B: Download MobileConfig Profile

  1. Click Download Security Profile (.mobileconfig) above.
  2. Open System Settings → Search for Profiles.
  3. Double-click King's School Bruton Web Security and click Install...
  4. You will be prompted for your Mac password.
  5. Select Update Settings.

Option C: Manual Keychain Access Setup

  1. Download Fortinet_CA_SSL.cer.
  2. Press Command + Space, type Keychain Access, and press Enter.
  3. In the left sidebar, click on login under Keychains.
  4. Drag and drop the downloaded certificate into Keychain Access.
  5. Locate and double-click the Fortigate / Fortinet certificate.
  6. Click on the arrow next to Trust to expand settings.
  7. Click on the dropdown next to Secure Sockets Layer (SSL) and select Always Trust.
  8. Click the red Close (X) icon in the top-left corner and enter your Mac password when prompted to save changes.
