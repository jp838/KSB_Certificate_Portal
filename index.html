Installation Instructions

  1. Click Copy Auto-Install Command above.
  2. Press Win + R on your keyboard, type powershell, and press Enter.
  3. Right-click in the blue window to paste, then press Enter.

Alternatively, download the .crt file directly to install manually.

  1. Tap Download Fortinet Certificate above and tap Allow on the prompt.
  2. Open your device Settings app.
  3. Tap Profile Downloaded (near the top).
  4. Tap Install in the top-right corner and enter your passcode.
Mandatory iOS Step:
Go to Settings > General > About > Certificate Trust Settings.
Under "Enable full trust for root certificates", toggle ON trust for Fortinet_CA_SSL.
  1. Tap Download Fortinet Certificate (.crt) above.
  2. If prompted by Android, select CA Certificate / Wi-Fi Certificate to install directly.
  3. If not prompted, open Settings → Search for CA Certificate.
  4. Select Fortinet_CA_SSL.crt from your Downloads folder.
  1. Click Download Fortinet Certificate above and double-click the file to open.
  2. In Keychain Access, locate Fortinet_CA_SSL under login or System.
  3. Double-click the certificate and expand Trust.
  4. Change When using this certificate to Always Trust.
  5. Close Keychain Access and enter your Mac password to confirm.
